## [0.1.0] — 首个可安装版本

首版。

### 新增

**中央库与链接管理**

- 中央库位置**完全可配置**：可放在任意盘符 / 文件夹，不必挤占 C 盘；
  选择时当场给出体检结论（文件系统是否支持链接、是否云同步目录、
  是否网络路径、剩余空间、路径长度）
- 一键启用 / 禁用：把中央库中的 Skill 通过 **junction** 映射到各 Agent
  技能目录；无需管理员权限，全程不弹 UAC
- 「Skill × Agent」映射矩阵：逐格展示真实链接状态（有效 / 未链接 / 断链 /
  被真实目录占用 / 外部链接）与两侧绝对路径，可导出 Markdown 报告
- 断链修复、冲突处理（跳过 / 备份并替换）、中央库位置迁移向导
- 纳入中央库：把散落在 Agent 目录里的 Skill 收归中央库，原位置替换为链接

**多 Agent 支持**

- 自动检测 Claude Code、Cursor、Codex、Windsurf、Trae 等 Agent 的安装状态与
  技能目录；检测为三态（未安装 / 已安装但无技能目录 / 已就绪），
  因为有些 Agent 的技能目录是**按需创建**的
- 为「已安装但技能目录不存在」的 Agent 一键创建目录
- 支持手动指定任意 Agent 的技能目录，也支持注册表之外的自定义 Agent

**搜索、标签与导入导出**

- 全文搜索（索引 SKILL.md 正文），支持 `tag:` / `agent:` / `is:enabled` /
  `is:external` / `is:dangling` 语法糖与命中片段高亮
- 标签页：标签云与计数、多选筛选、重命名 / 合并 / 删除，
  改动**写回 SKILL.md 的 frontmatter**（文件始终是唯一事实来源）
- 排序与视图（网格 / 列表）偏好持久化
- 导入：文件夹 / ZIP / Git 仓库地址 / 单个 SKILL.md，
  带预览、同名冲突逐项选择（默认跳过）
- 导出：ZIP（含 `manifest.json`）或纯目录结构

**GitHub 同步**

- 把中央库备份到**你自己已有的** GitHub 仓库（仓库里原本就有别的文件也没关系，
  它们不会被删除、也不会被提交）
- 两种登录方式：GitHub 账号浏览器授权，或手动填写 Personal Access Token；
  Token 存放在 **Windows 凭据管理器**，不落配置文件、不进日志
- 同步 = 只增改不删除；取回 = 只补齐不覆盖本地已有的 Skill

**其它**

- 首次运行引导（选择中央库 → 连接 Agent → 启用第一个 Skill）
- 深色 / 浅色主题跟随系统并可手动覆盖

### 已知限制

| 限制 | 说明 |
| --- | --- |
| **安装包未签名** | 没有代码签名证书。Windows SmartScreen 会提示"未知发布者"，需点击"更多信息 → 仍要运行"。详见 [`docs/DISTRIBUTION.md`](docs/DISTRIBUTION.md) |
| **仅支持 Windows** | 链接功能依赖 NTFS junction。链接层已抽象为 `platform` 模块并为非 Windows 保留了显式报错的占位实现，但**尚未在非 Windows 平台上编译验证过** |
| **中文搜索用 trigram** | 索引对中文采用 trigram 子串匹配，两字中文查询会退化为扫描（结果正确，但排序语义弱于专用中文分词） |
| **卸载不清理数据** | 这是有意为之：卸载不会删除中央库与配置。卸载界面上那个"删除应用数据"勾选框**对本应用无效**（原因见 DISTRIBUTION.md），勾了也不会删掉你的 Skill |
| 删除 Skill 后仓库里的副本保留 | 同步"绝不删除"的必然代价。需要清理时请在 GitHub 网页上手动删除 |
